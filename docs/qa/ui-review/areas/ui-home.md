## A11y & Consistency

**F1 (high) — Focus rings are invisible on most Home interactives.** Global `:focus-visible { outline: 2px solid var(--focus) }` (`styles/base.css:55-59`) is overridden by module rules using the shorthand `outline: var(--focus)` where `--focus` is a **bare color** (`styles/styles.css:89,120,139`). `outline: <color>` leaves `outline-style` at its initial `none`, so no ring is drawn — and the higher-specificity module rule kills the global one. Affected: `DoThisNext.module.css:49-52,162-165`; `ConditionsPreview.module.css:80-83,153-157`; `ShareCard.module.css:62-65` (pattern repeats in conditions/steps modules outside this area). Fix: `outline: 2px solid var(--focus)` or define `--focus` as a full shorthand.

**F2 (high) — Color-only encodings.** Priority dots (`DoThisNext.tsx:79-82`) and EvidenceHealth stacked bars (`EvidenceHealth.tsx:53-63`) convey meaning by color alone; SR users get no priority and no partial/missing split (only "x/y strong" is text).

**F3 (medium) — Conditions "table" has no table semantics.** Div/anchor grid (`ConditionsPreview.tsx:37-72`) — no `role="table"/row/columnheader"`, so header↔cell relationships are lost to AT.

**F4 (medium) — Modal lacks focus trap and focus return.** `Modal.tsx:18-27` focuses the card and handles Esc but Tab walks out of the dialog; closing doesn't restore focus to the invoking step card.

**F5 (medium) — Progressbar without accessible name.** `AnalyzingState.tsx:16` has role/values but no `aria-label`.

**F6 (medium) — Contrast risks in hero.** Labels/notes at 62-66% white opacity over the navy gradient (`HomeHero.module.css:59,83,123`) at 0.72-0.8rem; disclaimer footnote 0.78rem in `--faint` (`HomeView.module.css:38-45`). Verify ≥4.5:1.

**F7 (low) — Em-dash placeholders** for missing VASRD code / non-ratable rating (`ConditionsPreview.tsx:51,65,87`) have no SR-friendly text.

**F8 (low) — Tooltip-only detail on touch.** TriadDots `title` attributes (`TriadDots.tsx:23`) are the only expansion of Dx/IS/Nx on the mobile-only glance card.

**Token/consistency violations:**
- Raw `rgba()` literals throughout `HomeHero.module.css:28,49,59,75,83,102,123,181` — violates the "every color is `var(--…)`" charter (`lib/theme/tokens.ts:3-8`); dark mode (`styles/styles.css:151-176` `.cp-dark`) can't recolor them (white-on-navy survives, but the purple glow is fixed).
- Magic numbers: rail `340px` + sticky `top: 92px` (`HomeView.module.css:8,26`), repeated in `loading.module.css:8`; assorted px paddings (e.g., `padding: 26px 32px`, `13px 18px`) alongside `--s*` spacing tokens — two sizing systems in one area.
- Breakpoint duplication: 759.98px (component mobile) vs 1100px (grid collapse) — between 760-1100 the rail stacks under main while components render "desktop" variants; intended, but undocumented.
- Dead prop: `readyCount` is in `ConditionsPreviewProps` and passed by HomeView (`HomeView.tsx:58`) but never destructured/used (`ConditionsPreview.tsx:22`).
- Fixture/adapter level mismatch: fixtures use `"moderate" | "weak"` (`lib/fixtures/home.ts:8`) vs UI `TriadLevel = "strong" | "partial" | "missing"` — mapping lives in `toCondition`; fine, but the fixture type alias hides it.

## Verdict

The populated Home is **well-storied at the macro level** — hero → do-this-next → conditions → evidence/pay/share is a coherent veteran narrative, and the four fixture states (populated/empty/analyzing/overflow) show real state discipline. But the **action layer is hollow**: the two buttons that convert insight into work (modal "Add evidence" / "View condition") are dead, condition rows don't deep-link, steps have no overflow path, and a returning veteran has no upload entry at all. The pay card ships dead SMC code and a duplicate "Potential total". Free/Pro is computed but never surfaced, the analyzing state never refreshes itself, and a swallowed calc error masquerades as "0% / $0". On a11y, one systemic bug (the `outline: var(--focus)` shorthand) silently removes keyboard focus visibility across nearly every interactive element in the area. Recommend: fix the dead CTAs + focus shorthand first (small diffs, high impact), then wire deep links and the calc-failure/zero-gap/no-ready-mobile states, then either implement SMC or cut the two pay rows.
