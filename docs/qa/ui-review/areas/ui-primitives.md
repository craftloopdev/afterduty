Scope: `web/src/components/ui/{Button,Chip,Pill,EmptyState,ErrorState,Icon,Modal,Sheet,Skeleton,DisclaimerPill}` + sibling `.module.css`, `web/src/lib/theme/tokens.ts` (+ `tokens.test.ts`, `prefs.ts`), and the token layer `web/src/styles/{styles.css,base.css}`. ## Orphans (no honest user story → candidates to cut or finish)

1. **Six unused icon glyphs** — `clock`, `doc2`, `money`, `pen`, `sign`, `steps` (`components/ui/Icon.tsx:71` (steps), `:142-148` (money), `:177-181` (pen), `:183` (send is used; sign `:184-189`), `:190-195` (doc2), `:196-201` (clock)). Zero consumers anywhere in `web/src` (verified by per-name grep excluding Icon.tsx; nav arrays use `home/conditions/target/file/person`). They were ported wholesale from the prototype's `app/icons.jsx` and ship in every client bundle because `PATHS` is one object. Either delete or leave with a comment claiming them for the roadmap (e.g. `money` for ratings, `pen` for statements) — right now they're dead weight.
2. **`resolveStatusIcon`** (`lib/theme/tokens.ts:39-46`) — exported, unit-tested (`tokens.test.ts:44-48`), consumed by nobody. Components that render status (StatusTag, TriadDots) use `statusColors` only. Dead public API; the test green-washes it.
3. **Sheet `full` prop** (`components/ui/Sheet.tsx:11,32`, `Sheet.module.css:21-23`) — double orphan: the CSS sets `max-height: 88vh`, identical to the base `.sheet` rule (`Sheet.module.css:14`), so it is a visual no-op; and no caller passes it (Sheet's only consumer is `app/(auth)/login/page.tsx:222`). Remove prop + rule, or make `full` actually mean 100dvh.
4. **Sheet grab handle** (`Sheet.tsx:37`, `Sheet.module.css:25-31`) — decoration masquerading as function. The 38×5px pill is the universal "drag me" affordance, but there is no pointer/touch handler; dismissal is scrim-tap, Escape, or the X. Either implement swipe-to-dismiss or accept that the handle is lying to mobile users.

## Missing Affordances (stories with no supporting element)

1. **"As a veteran, I want a brief confirmation when an action succeeds (link copied, invite sent, document uploaded, step added) so that I trust it worked."** — No toast/snackbar primitive exists anywhere (`grep -ri toast|snackbar` → zero hits). Success feedback is currently silent or relies on list mutation.
2. **"As a veteran deleting my account, I want the destructive button visually red so that I cannot confuse it with a normal action."** — Button has only `primary|ghost` (`Button.tsx:7`); the delete-account confirm patches primary with a one-off `styles.confirmDanger` class (`components/profile/ProfileView.tsx:236-243`). The design system should own a `danger` variant.
3. **"As a keyboard/SR user, I want focus held inside an open Modal/Sheet and returned to the trigger on close so that I don't get lost in the page underneath."** — No focus-trap or focus-restore utility exists; Modal does initial focus only (`Modal.tsx:20`), Sheet does nothing.
4. **"As a SR user, I want to hear that the page is loading."** — Skeletons are `aria-hidden` (`Skeleton.tsx:25,38`) and `app/(app)/loading.tsx` adds no visually-hidden live text; loading is invisible to AT.
5. **"As a veteran with flaky connectivity, I want a non-fatal inline warning (offline, AI partially unavailable) so that I know why something is stale without losing the page."** — Only the full-page ErrorState exists; no banner/inline-alert primitive.
6. **"As a veteran filling in my email/phone, I want a standard labelled input with inline error text so that mistakes are explained next to the field."** — No Input/FormField primitive; login (`app/(auth)/login/page.tsx`) and profile roll bespoke fields, so error presentation can drift per screen.
7. **"As a touch user, I want the 'Educational' pill's explanation reachable without a hover tooltip."** — Partially covered (clicking opens DisclaimerModal), but the `title` attribute (`DisclaimerPill.tsx:12`) is the only hint of *what the pill is*, and `title` is unreachable on touch and most AT. A Tooltip primitive (or visible affordance) is missing system-wide.
8. **"As a mobile veteran, I want to swipe the bottom sheet closed."** — Handle exists, gesture doesn't (see Orphan 4).
9. **"As a veteran reading an untitled dialog, I want an X to close it."** — Modal's close button is title-gated (`Modal.tsx:43-49`); DisclaimerModal consequently has no X and relies on its own "Got it" button + Escape/scrim.

## A11y & Consistency

**Accessibility**
- **Sheet is not a dialog to AT**: no `role="dialog"`, no `aria-modal`, no accessible name, no focus move (`Sheet.tsx:35-48`). Highest-severity a11y gap in this area — the phone sign-in flow rides on it.
- **Modal**: no focus trap, no focus restore to trigger; `aria-label={title}` is `undefined` for untitled use (`Modal.tsx:39`; live case `DisclaimerModal.tsx:15`). Prefer `aria-labelledby` pointing at the rendered `h3`, plus a required-name API.
- **Chip lacks `aria-pressed`** (`Chip.tsx:15`): active filter is conveyed by color alone; also no non-color differentiator (e.g. check glyph) for color-blind users.
- **Tap targets below 44px**: Button `sm` 38px (`Button.module.css:30`) contradicting the 44px comment at `:13`; Modal close 32px (`Modal.module.css:60-62`); Sheet close 38px (`Sheet.module.css:46-48`).
- **No live regions**: ErrorState swap (`app/(app)/error.tsx`) and skeleton loading are silent to SR; Button `aria-busy` is the only async signal.
- **Reduced motion**: well handled three ways (`base.css:68-77` global, `Modal.module.css:29-33`, `Sheet.module.css:61-74`, `Skeleton.module.css:30-36`) — but the global kill also freezes the Button spinner into a static arc; consider a reduced-motion loading treatment.
- **Contrast to verify**: 0.72rem Pill text for all tone pairs (esp. `--partial #8a5a0f` on `#fff1d6`); disabled Button at opacity .55 (exempt but worth a look); dark-mode focus ring (`--focus` never overridden in `.cp-dark`).
- **Positive notes**: Icon's `title`→`role="img"`/else-hidden contract (`Icon.tsx:218-220`) is exemplary; `:focus-visible` ring is tokenized and theme-aware; SSR'd theme cookie kills the dark-mode flash; `min-height: 44px` default on Button; Escape handling on both overlays.

**Design-token discipline**
- `tokens.test.ts` enforces no-hex **only for tokens.ts**; the CSS modules leak raw colors the test can't see: Modal scrim `rgba(10,18,35,0.42)` (`Modal.module.css:4`), Sheet scrim `rgba(15,20,32,0.5)` (`Sheet.module.css:4`), Sheet close bg `rgba(120,130,150,0.12)` (`Sheet.module.css:53`), Chip active count `rgba(255,255,255,0.2)` (`Chip.module.css:35`). Suggest `--scrim` and `--overlay-soft` tokens + a stylelint rule.
- Hardcoded radii: `11px` (`Button.module.css:29`), `26px 26px 0 0` (`Sheet.module.css:13`), `999px` (`Sheet.module.css:28` — `--r-pill` exists for exactly this).
- The spacing scale `--s4..--s24` (`styles.css:72-81`) is almost entirely unused by these primitives — paddings are literals (`9px 14px`, `13px 18px`, `40px 24px`, `8px 20px 24px`). Either adopt the scale or drop it; today it's aspirational.
- Inconsistency: **Sheet locks body scroll, Modal doesn't** (`Sheet.tsx:22-27` vs `Modal.tsx` none) — long pages scroll behind centered modals.
- Duplication: ErrorState's CSS is a near-copy of EmptyState's (`ErrorState.module.css` vs `EmptyState.module.css` — same layout, circle, title, body). ErrorState could compose EmptyState with a tone prop, guaranteeing the two never drift.
- Minor semantics: retry icon `bolt` (`ErrorState.tsx:22`) reads "power/energy," not "retry"; Sheet title is a `div` not a heading (`Sheet.tsx:40`).

## Verdict

This is a small, disciplined primitive set — every *component* in scope earns a defensible user story, the token layer (3 themes + shared dark + text scale, var-only, unit-tested) is genuinely better than most production apps, and Icon's a11y contract is a model. The waste is at the edges: 6 dead icon glyphs, one dead resolver (`resolveStatusIcon`), a no-op `full` prop, and a grab handle that promises a gesture nobody wrote. The serious debt is interactive a11y on overlays — Sheet is invisible to assistive tech and Modal traps nobody — plus three system-level holes the app is already papering over by hand: no toast, no danger button (ProfileView patches one), no form-field primitive. Fix the overlay semantics and add those three primitives before more feature surface area hardens around the workarounds.

**Score: components 10/10 storied; sub-element orphan rate ~4/45; a11y: 2 blockers (Sheet dialog semantics, Modal focus trap), 6 moderates.**
